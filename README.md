# India's Agricultural Crop Production Analysis

## Project Overview

India's Agricultural Crop Production Analysis is a Tableau-based data visualization project that analyzes agricultural crop production data using an Excel dataset obtained from Kaggle.

The project focuses on analyzing agricultural production based on **State, Crop, Year, and Season**. Tableau was used to transform the raw data into interactive charts, KPI cards, maps, filters, a dashboard, and a Story.

The project also includes a web-integrated version deployed using **Vercel**, making the project accessible through a web browser.

## Objectives

- Analyze agricultural crop production.
- Compare production across different states and crops.
- Identify yearly and seasonal production trends.
- Analyze state-wise production geographically.
- Create an interactive Tableau dashboard.
- Present insights through a Tableau Story.
- Provide a web-based interface for the project.

## Visualizations

The project includes:

1. Production by State – Bar Graph
2. Production by Crop – Bar Graph
3. Production Trend by Year
4. Season-wise Production
5. State Production Map
6. Total Production KPI
7. Total Cultivated Area KPI
8. Average Yield by State
9. Season-wise Pie Chart

## Interactive Dashboard

The dashboard combines the major visualizations, KPI cards, map, and interactive filters.

**Filters:**
- State
- Crop
- Year
- Season

## Tableau Story

The Tableau Story presents the analysis through the following Story points:

1. Crop-wise Production Analysis
2. Production Trend by Year
3. Season-wise Production Analysis
4. State-wise / Average Yield Analysis
5. Final Interactive Dashboard

## Web Integration

A web-based interface was created to provide easy access to the project through a browser. The web application presents the agricultural analysis in an application-oriented format and is deployed using **Vercel**.
